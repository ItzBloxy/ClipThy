**Instant replay for the Windows desktop.** ClipThy sits in the tray and keeps the last 15–120 seconds of your screen, system audio and microphone in memory. Press <kbd>Alt</kbd>+<kbd>F10</kbd> and they're an MP4 a second or two later.

This is the first public release.

## Highlights

- **Two save hotkeys.** <kbd>Alt</kbd>+<kbd>F10</kbd> saves one mixed audio track. <kbd>Alt</kbd>+<kbd>F11</kbd> saves three tracks (Mix, System, Mic) for editing.
- **Hardware H.264** through NVIDIA NVENC, falling back automatically to Media Foundation if NVENC can't start.
- **Light on resources:** about 0.4 % of one CPU core and ~190 MB of RAM with a 30 s buffer, and no disk writes until you save.
- **In sync:** video and audio share one capture clock and are aligned at save time (measured +9 ms offset, 0.05 % dropped frames at 60 fps).
- **Smooth 60 fps,** because ffmpeg gets a 1 ms Windows timer.
- **Recovers on its own** from sleep, lock, display changes, ffmpeg crashes and audio device changes.
- **ShareX-style output:** `Documents\ShareX\Screenshots\yyyy-MM\clip_yyyy-MM-dd_HH-mm-ss.mp4`, a soft chime, and a notification that opens the clip in Explorer.

## Install

1. Install **ffmpeg 8** so it's on your PATH, for example with `winget install Gyan.FFmpeg`.
2. Unzip ClipThy somewhere permanent and run `ClipThy.exe`. A red dot appears in the tray.
3. Press <kbd>Alt</kbd>+<kbd>F10</kbd>.

> [!NOTE]
> The exe isn't code-signed, so SmartScreen may warn you the first time: click **More info → Run anyway**. ClipThy also adds itself to **Start with Windows** on first run; untick it in the tray menu if you don't want that.

## Requirements

- 64-bit Windows 10 or 11 (tested on Windows 10 22H2)
- A GPU with a hardware H.264 encoder. NVIDIA is tested and needs driver 570+ for ffmpeg 8. AMD and Intel should work through Media Foundation but are untested.
- ffmpeg 8 with `ddagrab` (gyan.dev's full build has everything)

## Known limitations

- Records the primary monitor only, in 8-bit SDR. Turn Windows HDR off for correct colours.
- NVIDIA's overlay uses <kbd>Alt</kbd>+<kbd>F10</kbd> too. If it got there first, ClipThy tells you; change `hotkeyMixed` in `%APPDATA%\ClipThy\config.json`.
- Windows shows the microphone-in-use icon while ClipThy runs, because the mic is always being buffered (in RAM only).

See the [README](https://github.com/ItzBloxy/ClipThy#readme) for configuration, troubleshooting and how it works.
